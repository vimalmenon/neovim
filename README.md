# NVIM Config

This is my NVIM configuration

### Icons

Icons require a [Nerd Font](https://www.nerdfonts.com/font-downloads) to be installed and selected in the terminal running Neovim. The configuration currently enables Nerd Font icons.

#### Navigation

- `o` Open a new line
- `O` Open new line above
- `i` Insert mode at beginner
- `I` Insert mode at start of line
- `a` Insert mode at end
- `A` Insert mode at end of line
- `e` Move to end of work
- `b` Move back of word
- `w` Move to beginning of word
- `f <letter>` Go to word
- `t <letter>` Go to work before
- `.` Repeat the step
- `u` Undo the step
- `\` Open side panel
- `<space>` leader key


##### Insert / Append

- `r` Replace a letter
- `cw` Change word
- `ciw` Change inner word
- `ea` Insert at end of word
- `bi` Insert at beginning of word
- `viwc` Replace word and start inserting


###### Lazy Git

- `<space> lg` Open lazy git
- `p` Pull from upsteam
- `P` Push to upsteam


###### Other Navigation

- `<ctrl> q` Quit
- `<ctrl> h` Move to left window
- `<ctrl> l` Move to right window
- `<ctrl> j` Move to down window
- `<ctrl> k` Move to up window
- `<ctrl> s` saves the file
- `0v$` \ `^v$` Select whole line


###### Buffer Operation

- `<space> bn` Go to next buffer
- `<space> bp` Go to previous buffer
- `<space> bd` Delete the currect buffer


###### Change Color Theme

- `:Telescope colorscheme` change the color scheme
- `:Themery` Change color theme with live preview


###### File Helper

- `H` Show hidden files
- `a` Create a new file
- `i` Show file info


###### NVIM Helper

- `<space> sk` Find the key binding
